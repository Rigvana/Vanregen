# Updating the Van Regen website

Publish changes in WordPress and refresh the WordPress site to see them. The
standalone Vite development page does not load WordPress content.

- **Page copy:** Edit page titles and content in **Pages**. The Home, Services,
  Contact, and Projects pages also have **Van Regen Frontend Copy** fields for
  their editable sections.
- **Hero media:** Each Page, Service, Project, and Post has a **Hero Media**
  box. Choose an image or video from the Media Library for that record only.
  The Home, Services, and individual Service heroes use their own settings;
  they do not inherit another page's video.
- **Projects:** Add, edit, publish, or unpublish entries under **Projects**.
  The Projects page contains two sections: published project records and a
  page-level gallery. Set a Featured Image for each project card and use its
  **Project Photos** box for that project's detail gallery. Manage the separate
  Projects page gallery and section copy on **Pages > Projects**.
- **SEO:** Set global defaults, social accounts, and Organization details
  under **Settings > Van Regen SEO**. Each Page, Service, Project, and Post
  has an **SEO Settings** box for its title, description, canonical URL,
  social preview, indexing directive, and optional XML sitemap exclusion.
  Blank per-record values use the site defaults or generated content. The
  theme supplies canonical, robots, Open Graph, X/Twitter, Organization,
  website, page/article/service, and breadcrumb structured metadata.
- The homepage shows up to four published Services and three published
  Projects; their directory pages show all published records. Draft records
  are not shown on the public site.
- **Logo:** Set the logo under **Appearance > Customize > Site Identity**.
  If no custom logo is set, the Site Icon is used instead.
- **Navigation:** The default menu includes published services automatically.
  To customize it, create a menu under **Appearance > Menus** and assign it to
  **Primary Navigation**. Add service links to that menu explicitly; nested
  menu items become dropdowns. The footer uses the same menu.
- **Quote products:** On each Service editor, use the **Quote Product Options**
  repeatable rows to add, remove, and order the products shown after that
  service is selected on the Ask a Quote page.
- **Inquiries:** Contact and quote submissions appear under **Website Inquiries**.
  Configure the notification recipient and SMTP delivery under **Settings >
  Van Regen SMTP**. Inquiry pages show email-delivery status and links for
  replying to the submitter in Gmail or another configured email application.

The layout, some labels, background media, and calculator behavior remain part
of the theme rather than WordPress-editable content. Private inquiries and mail
settings are not displayed publicly.
